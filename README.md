# 🚀 AI 降重系统 (AI Content Polisher & Anti-Detection System)

## 📖 项目简介

本系统是一款基于大语言模型（LLM）的“降重引擎”。
它不仅仅是简单的同义词替换，而是通过底层逻辑重构、深度行为模拟、以及双语言范式架构，将充满“AI 味”的冰冷文本转化为极具人类情绪和逻辑特征的高维文本，从而轻松绕过各类 AI 检测工具。

## ✨ 核心亮点

🍏 Apple 级 UI 设计：纯正的毛玻璃（Glassmorphism）质感，沉浸式操作空间，支持原生级暗黑/浅色模式无缝切换。**完全的图形化界面！**

⏱️ 真实 3D 机械翻牌器：引入流式字数预估引擎，Token 消耗如同机械时钟般丝滑滚动，极具物理反馈感。

⚡ 上下文缓存 (Prompt Caching) 侦测：深度对接阿里千问、DeepSeek 等大厂的隐式缓存协议。自动抓取命中缓存的 Tokens 并单独点亮绿色徽章，省钱进度一目了然！

🧠 强制接管“深度思考”：底层代码自动适配全网主流模型（o1、Qwen、DeepSeek 等），可通过控制台一键剥夺或开启模型的 Reasoning（推理）能力。

🌊 两段式实时打字机：支持长文分段异步流式输出（Streaming），处理进度实时反馈，且自带“切分边界高亮”透视功能。

## 🛠️ 安装与运行指南（建议使用作者已经构建好的版本）

#### 方式一：源码运行 (开发者模式)

确保你已安装 Python 3.8+ 环境。

安装所需依赖包：

`pip install -r requirements.txt`


运行核心程序：

`python main.py`


启动后，程序会自动在浏览器中打开 http://127.0.0.1:8000。

#### 方式二：一键打包 (发布给他人使用)

如果你想把程序发给没有 Python 环境的朋友使用，只需运行打包脚本：

在项目目录中双击运行或在终端执行：

`python build.py`


等待控制台跑完进度，打包完成后，项目里会多出一个 `dist` 文件夹。

进入 `dist` 文件夹，里面会生成一个完整文件夹（包含所需的所有环境依赖和运行程序）。

将这个文件夹发给任何人，他们双击即可直接使用，自动打开网页！

🔐 隐私与安全说明 (必读)

绝对的数据安全：本程序完全在你的本地设备与大模型官方 API 之间点对点通信，没有任何中间服务器截留数据。

API Key 本地隔离：你在页面中输入的 API Key 等信息会被保存在程序同级目录的 `config.json` 文件中。

打包分发保护：使用 `build.py` 打包成 .exe 发送给他人时，你本地的 `config.json` 绝不会被打包进去，你的 API Key 绝对安全。当他人运行程序并输入自己的 API 时，程序会在他们本地生成属于他们的 `config.json`。
