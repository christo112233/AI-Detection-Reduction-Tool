# 🚀 AI 降重系统 (AI Content Polisher & Anti-Detection System) 
## 📖 项目简介
本系统是一款基于大语言模型（LLM）研发的智能文本降重与反检测引擎。不同于传统简单的同义词替换方式，系统通过文本底层逻辑重构、人类写作行为深度模拟及双语言范式架构，将具有明显 “AI 生成特征” 的生硬文本，转化为兼具人类情绪表达与逻辑连贯性的高维度自然文本，可高效绕过各类主流 AIGC 检测工具，适用于学术写作、文案优化等多场景文本处理需求。同时，本系统已实现与 AIGC 检测工具 DeepVeri 的跨软件深度联动，构建 “检测 - 降重 - 再检测” 的全流程闭环，进一步提升文本处理效率与效果。
## ✨ 核心亮点
📱 Apple 级视觉交互设计：采用纯正毛玻璃（Glassmorphism）设计质感，打造沉浸式操作界面，支持原生级暗黑 / 浅色模式无缝切换，全程采用图形化操作逻辑，无需专业技术基础，上手便捷。

⏱️ 3D 机械质感 Token 消耗可视化：集成流式字数预估引擎，Token 消耗状态以 3D 机械翻牌形式实时呈现，操作过程兼具丝滑流畅度与物理反馈感，消耗明细直观可见。

💰 上下文缓存（Prompt Caching）智能侦测：深度对接阿里千问、DeepSeek 等主流大模型的隐式缓存协议，可自动识别并抓取命中缓存的 Tokens，通过绿色徽章单独标记，缓存省钱进度清晰可追溯。

🧠 推理能力可定制化管控：底层代码已完成全网主流模型（o1、Qwen、DeepSeek 等）适配，支持通过控制台一键开启或关闭模型推理（Reasoning）能力，灵活匹配不同降重需求，兼顾效率与文本质量。

🌊 两段式实时流式输出：支持长文本分段异步流式处理（Streaming），实时反馈处理进度，内置 “切分边界高亮” 透视功能，精准定位文本处理节点，避免长文本处理卡顿。

🔗 跨软件联动赋能：已完成与 AIGC 检测工具 DeepVeri 的联动适配，通过本地 127.0.0.1:5005 端口实现稳定通信，启动两款工具后可自动完成数据交互，无需手动复制粘贴文本，一键打通 “检测 - 降重 - 二次检测” 全流程，彻底解决多工具切换操作繁琐的痛点。

## 🛠️ 安装与运行指南（建议使用作者已经构建好的版本）

#### 方式一：源码运行 (开发者模式)

确保你已安装 Python 3.8+ 环境。

安装所需依赖包：

`pip install -r requirements.txt`


运行核心程序：

`python main.py`


启动后，程序会自动在浏览器中打开 http://127.0.0.1:8000。

#### 方式二：一键打包 (发布给他人使用)

如果你想把程序发给没有 Python 环境的朋友使用，只需运行打包脚本：

在项目目录中双击运行或在终端执行：

`python build.py`


等待控制台跑完进度，打包完成后，项目里会多出一个 `dist` 文件夹。

进入 `dist` 文件夹，里面会生成一个完整文件夹（包含所需的所有环境依赖和运行程序）。

将这个文件夹发给任何人，他们双击即可直接使用，自动打开网页！

🔐 隐私与安全说明 (必读)

绝对的数据安全：本程序完全在你的本地设备与大模型官方 API 之间点对点通信，没有任何中间服务器截留数据。

API Key 本地隔离：你在页面中输入的 API Key 等信息会被保存在程序同级目录的 `config.json` 文件中。

打包分发保护：使用 `build.py` 打包成 .exe 发送给他人时，你本地的 `config.json` 绝不会被打包进去，你的 API Key 绝对安全。当他人运行程序并输入自己的 API 时，程序会在他们本地生成属于他们的 `config.json`。
